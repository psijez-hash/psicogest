# PsicoGest - Aplicación Clínica de Gestión de Pacientes y Sesiones

Una aplicación web moderna, rápida y 100% confidencial diseñada específicamente para psicólogos y terapeutas.

---

## 🚀 ¿Cómo abrir la aplicación?

1. Dirígete a la carpeta: `C:\Users\JjeZP\.gemini\antigravity\scratch\psicogest-app\`
2. Haz **doble clic** en el archivo `index.html` (se abrirá instantáneamente en tu navegador preferido: Google Chrome, Microsoft Edge, Firefox, Brave, etc.).
3. ¡Listo! No requiere instalar servidores, bases de datos complejas ni conexión a internet obligatoria.

---

## ✨ Funcionalidades Incluidas

1. **Gestión de Pacientes y Centros**:
   - Clasificación directa por tus centros: **Descubriendo**, **Psicovive** y **Particulares**.
   - **Deslizador Activo / Inactivo**: En "Editar Paciente" puedes deslizar el interruptor para marcar a un paciente como inactivo (archivado) cuando concluya su proceso.
   - **Filtros de Estado en Panel Lateral**: Pestañas de *"Activos"*, *"Inactivos"* y *"Todos"* para mantener tu lista diaria limpia y despejada.
   - Filtros rápidos por centro de trabajo.
   - Buscador en tiempo real por nombre de paciente o datos de consulta.
   - Selector rápido para no tener que volver a escribir los nombres al registrar sesiones.

2. **Visualizador de Objetivos Terapéuticos**:
   - Seguimiento visual de metas terapéuticas con estados: *Pendiente*, *En Progreso* y *Alcanzado*.
   - Barra de porcentaje de avance clínico.
   - Recordatorio automático de los objetivos activos mientras redactas la sesión clínica.

3. **Registro Ágil de Sesiones**:
   - Fecha y hora por defecto en el momento del registro (con botón *"Poner ahora"* o selector de cualquier otra fecha previa).
   - Numeración y tipo de sesión sugerido automáticamente.
   - Espacio amplio para notas de evolución y desarrollo de la sesión.
   - Sección dedicada para **Tareas Asignadas (Homework)**.
   - Sección dedicada para **Plan y Recomendaciones para la Próxima Sesión**.

4. **Historial de Sesiones y Cronología**:
   - Consulta ordenada de todas las sesiones de cada paciente.
   - Buscador interno de sesiones por palabras clave o temas tratados.
   - Botón para editar o eliminar sesiones anteriores si necesitas corregir detalles.

5. **Modo Privacidad / Confidencial**:
   - Botón en la barra superior que desenfoca los nombres de los pacientes en pantalla para proteger la confidencialidad si hay personas alrededor.

6. **Copias de Seguridad (Backup)**:
   - Exporta con un solo clic todos tus registros a un archivo `.json`.
   - Restaura copias de seguridad en cualquier momento o muévelas a otra computadora.

7. **Impresión y Exportación a PDF**:
   - Botón de imprimir adaptado para generar fichas clínicas en formato PDF formal y limpio.

---

## 📱 ¿Se puede usar en el celular?

¡Sí! La interfaz está diseñada de forma 100% responsiva (se adapta a pantallas de celulares, tablets y computadoras).
Tienes 2 formas muy sencillas de tenerla en tu teléfono:
1. **Opción Local / Archivo**: Puedes enviarte la carpeta o archivo `index.html` a tu celular o abrirlo en cualquier navegador móvil (Chrome / Safari).
2. **Opción Web Gratuita (PWA)**: Se puede subir a un hosting gratuito (como GitHub Pages, Vercel o Netlify) para acceder desde `https://tu-nombre.github.io/psicogest` y agregarla a tu pantalla de inicio como una app móvil real.
